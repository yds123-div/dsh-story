# 09 — 接受资产候选并进入视觉设定阶段

**What to build:** 用户可以审阅资产候选并明确接受它们；接受后项目进入视觉设定阶段，但不会错误地把资产候选当成已生成的正式视觉资产。

**Blocked by:** 08 — 运行资产拆解并展示资产候选

**Status:** ready-for-agent

- [ ] 用户可以查看资产候选及其来源证据
- [ ] 用户可以接受当前资产候选结果
- [ ] 接受动作记录关联的资产拆解运行
- [ ] 接受后项目进入视觉设定阶段
- [ ] 接受资产候选不会自动生成图片
- [ ] 候选、图片提示词和正式参考图保持不同概念
- [ ] 未接受资产候选时不能进入后续视觉设定生产
- [ ] 页面明确区分“资产候选已接受”和“正式视觉资产已生成”
- [ ] 后续视觉设定任务可以引用本次已接受资产候选
