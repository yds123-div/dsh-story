# 06 — 管理多次运行结果并选择当前剧本

**What to build:** 用户可以查看同一项目的多次生成结果，并选择一份作为待接受的当前候选；旧结果保留，不发生合并或覆盖。

**Blocked by:** 04 — 运行剧本生成并保存只读产物；05 — 展示剧本创作总览工作台

**Status:** ready-for-agent

- [ ] 用户可以查看项目的历史生成运行
- [ ] 每个运行显示创建时间、状态和输入来源
- [ ] 用户可以打开任意成功运行的只读产物
- [ ] 用户可以将某次成功运行选为当前候选剧本
- [ ] 未选定、已拒绝和已选定运行具有清晰状态
- [ ] 不同运行之间不能合并内容
- [ ] 选定运行不会自动绕过接受闸门
- [ ] 旧运行结果继续保留
- [ ] 运行列表可以区分当前候选和历史结果
