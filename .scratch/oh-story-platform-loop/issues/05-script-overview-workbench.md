# 05 — 展示剧本创作总览工作台

**What to build:** 用户可以在“总览 + 分阶段 Tab”的工作台中审阅当前剧本运行结果，而不是面对固定聊天内容或分散的调试数据。

**Blocked by:** 04 — 运行剧本生成并保存只读产物

**Status:** ready-for-agent

- [ ] 页面显示项目当前阶段和运行状态

- [ ] 页面提供剧本、分析、场景索引和资产候选 Tab
- [ ] 剧本 Tab 展示规范化正文和场景导航
- [ ] 分析 Tab 展示故事分析、角色目标、场景功能和制作检查
- [ ] 资产候选展示来源证据
