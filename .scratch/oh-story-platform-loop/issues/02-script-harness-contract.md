# 02 — 建立剧本阶段 Harness 执行契约

**What to build:** 产品后端能够通过稳定入口请求一次剧本阶段任务，并将 Harness 的运行、成功、失败、超时和产物结果转换为产品能够理解的统一任务状态。

**Blocked by:** 01 — 建立产品运行骨架

**Status:** ready-for-agent

- [ ] 产品 API 可以创建一次剧本阶段执行
- [ ] API 不暴露 Harness 内部实现给前端
- [ ] 支持任务运行中、成功、失败和超时状态
- [ ] 能够记录当前步骤、开始时间、结束时间和失败原因
- [ ] Harness 结果可以转换为产品侧的剧本产物结构
- [ ] 重复请求可以通过幂等语义避免重复创建同一运行
- [ ] 契约允许后续替换 Harness 调用方式，而不改变前端 API
