# 07 — 接受剧本并开放资产拆解

**What to build:** 用户接受选定的剧本产物包后，该运行成为项目当前有效剧本，并且只有此时才允许进入资产拆解。

**Blocked by:** 06 — 管理多次运行结果并选择当前剧本

**Status:** ready-for-agent

- [ ] 用户只能接受一份已成功且已选定的剧本运行
- [ ] 接受内容包括规范化剧本、分析、场景索引、资产候选和制作检查
- [ ] 接受后该运行成为项目当前有效剧本
- [ ] 接受动作记录时间和关联运行
- [ ] 接受前不能运行资产拆解
- [ ] 接受后项目进入“剧本已接受”或等价状态
- [ ] 接受后显示运行资产拆解的主操作
- [ ] 已接受剧本不能被前端直接修改
- [ ] 已接受结果不会被后续重新生成覆盖
- [ ] 拒绝或重新生成不会改变当前已接受剧本
