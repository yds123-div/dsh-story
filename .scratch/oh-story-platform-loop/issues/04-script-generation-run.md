# 04 — 运行剧本生成并保存只读产物

**What to build:** 用户可以从项目发起剧本生成，看到任务状态，并在成功后获得一组独立的只读剧本产物。

**Blocked by:** 02 — 建立剧本阶段 Harness 执行契约；03 — 创建项目并保存原始剧本输入

**Status:** ready-for-agent

- [ ] 用户可以从项目发起剧本生成
- [ ] 页面显示运行中、成功、失败和超时状态
- [ ] 页面显示开始时间、结束时间、当前步骤和失败原因
- [ ] 成功运行保存独立的剧本产物包
- [ ] 产物包至少包含剧本分析、规范化剧本正文、场景索引和资产候选
- [ ] 每次生成都创建独立运行结果
- [ ] 新运行不会覆盖旧运行
- [ ] 成功产物只读
- [ ] 任务失败时保留可追踪的失败运行记录
- [ ] 网络重试不会意外创建重复运行
