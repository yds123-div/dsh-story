0. 业务特征梳理与监控范围

通过对线上站点 /deepsfv/ 的实际访问观察，该插件是一个「剧本/短剧 AI 创作工作台」，已具备以下可观测的功能实体，这些实体直接决定了监控指标体系的设计边界：

观察到的实体业务含义监控含义
New Session新建创作会话会话创建行为，创作启动漏斗的第一环
task-xxxxxxxx剧本生成任务（含时长参数，如 "3集53min"、"仿写23h"）核心创作行为单元，Token 消耗的主要载体
story剧本正文/故事内容内容交付物，用于质量与完成度指标
tunnel-scripts隧道脚本（远程执行/隧道管理）系统管理行为，属运维类操作事件
?token=… 鉴权Token 无状态鉴权（302 携带 token，无 token 返回 401）登录/访问事件可从 Nginx 日志直接采集
任务题材样例"雍正王朝宫斗剧"、"青茅山集市聚宝盆（玄幻）"题材偏好 → 画像标签的直接数据源
由此得出插件的「一次完整创作」数据主线：
用户登录(token 鉴权) → 创建会话(New Session) → 创建剧本任务(task-*) → 多轮 AI 调用(文本生成 → 图像生成 → 视频生成) → 产出 story 交付 → 任务完结

全部指标体系围绕这条主线展开：人（用户/登录）→ 行为（会话/任务/分类）→ 物（画像标签）→ 钱（Token/模型/成本）。

1. 指标体系总体架构（分层模型）

参照数据仓库经典分层，结合插件单机 Nginx + 任务执行器的轻量架构，采用 五层模型，保证"落地性优先"：每层均可由当前服务器已有组件（Nginx 日志、任务执行器钩子、模型网关）直接产出。

层级名称内容落地载体（本机）
L-采ODS 采集层原始事件：Nginx access 日志（token/401/IP/UA）、任务生命周期事件、模型网关每次调用的 request/response 记录Nginx json 格式日志、插件埋点钩子、网关代理日志
L0DWD 明细层结构化明细表：登录事件表、会话表、任务表、AI 调用流水表（含每次调用的 prompt_tokens / completion_tokens）SQLite/ClickHouse 明细表
L1DWS 汇总层按 用户×日、用户×任务、模型×日 等粒度汇总的行为与 Token 指标定时聚合任务（cron + SQL）
L2ADS 应用层面向场景的指标：留存漏斗、行为分类、成本归因、告警规则计算指标结果表 + 告警引擎
L3画像层用户标签库：基础属性、题材偏好、价值分层、生命周期、风险标记用户标签宽表（每日更新）

四大主题域划分（后文逐一展开）：

主题域名称核心问题服务对象
T1用户资料与登录监控谁在何时从哪来、能否正常进入、是否有攻击运维 / 安全
T2行为分类与行为监控用户在产品里做什么、做到哪一步、为什么流失产品 / 运营
T3用户精准画像用户是谁、喜欢什么题材、值多少钱、会不会流失运营 / 增长
T4Token 消耗与模型调用每次生成烧了多少 Token、调用的是哪个模型、一单剧本成本多少成本 / 技术

2. 主题一：用户资料与登录监控 T1

该插件采用 Token 无状态鉴权（302 下发 token、无 token 返回 401），且服务器 SSH 已关闭密码登录——登录监控同时覆盖产品级（token 鉴权）与系统级（SSH 密钥登录）两个视角。

3.2 用户行为分类（人群分层规则）

行为分层判定规则（可配置阈值）运营含义

B 试创作型近 7 日创建任务 ≤ 2 个且无交付激活关键期，关注失败原因

5. 主题四：Token 消耗与模型调用 T4

R3任务执行器钩子 → Task → 创作漏斗/任务成功率 → 行为分层(A–F)任务成功率 = 完结task ÷ 创建task；分层按 7 日滑动窗口规则判定T2
R4Task → 1:N → 文本/图像/视频调用 → 调用流水表每行流水 = 1 次模型调用（含 tokens/成本/成败）T4
R5调用流水 → 按 模型/用户/任务 分组求和 → T4 Token 指标总Tokens = Σ(prompt)+Σ(completion)；图像/视频按等价系数折算T4
R6Token 指标 × 单价 → 成本归口 → 画像 M 值 / 成本报表单任务成本 = Σ(该task全部流水成本)；浪费率 = 失败流水消耗 ÷ 总消耗T4→T3
R7题材/时长/集数参数 → 题材偏好标签题材偏好 = 近30日任务题材频次 Top3T2→T3
R8画像标签 → 告警阈值/运营策略 → 回流影响用户行为策略闭环：召回↑活跃、限流↓消耗异常T3→T1/T2/T4

注：R1/R2 为登录主链与安全支线；R8 为策略回流闭环——召回提升活跃、限流抑制消耗异常，形成可验证的指标回路。
