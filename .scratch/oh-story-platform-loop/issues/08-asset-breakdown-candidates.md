# 08 — 运行资产拆解并展示资产候选

**What to build:** 用户可以针对已接受剧本运行资产拆解，并在完成后查看带来源证据的只读资产候选。

**Blocked by:** 07 — 接受剧本并开放资产拆解

**Status:** ready-for-agent

- [ ] 只有已接受剧本的项目可以发起资产拆解
- [ ] 资产拆解运行关联到明确的当前有效剧本
- [ ] 页面显示资产拆解任务状态和失败原因
- [ ] 资产候选至少区分角色、地点、道具或其他资产类型
- [ ] 每个候选保留来源场景或正文证据
- [ ] 资产候选与正式视觉资产明确区分
- [ ] 资产候选生成结果只读
- [ ] 任务失败时可以重试
- [ ] 已成功生成的候选不会因局部失败而被删除
- [ ] 重复请求遵循幂等语义
