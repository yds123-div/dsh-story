# 03 — 创建项目并保存原始剧本输入

**What to build:** 用户可以创建一个项目，并通过粘贴或上传方式保存原始剧本输入；原始输入不会被在线修改，后续生成运行可以明确引用它。

**Blocked by:** 01 — 建立产品运行骨架

**Status:** ready-for-agent

- [ ] 用户可以创建项目并填写基本信息
- [ ] 用户可以粘贴原始剧本文本
- [ ] 用户可以上传原始剧本文件
- [ ] 原始文本或文件保存到本地运行目录
- [ ] 数据库保存原始输入的类型、路径、大小和创建时间
- [ ] 每次剧本生成都能关联到明确的原始输入
- [ ] 首期不提供项目所有者、协作者和角色字段
- [ ] 首期不提供在线修改原始输入的能力
